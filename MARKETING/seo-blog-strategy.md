## Blog On-Page SEO Checklist

For each article:
- [ ] Target keyword in title
- [ ] Target keyword in first 100 words
- [ ] H1 with target keyword
- [ ] 2-3 H2s with related keywords
- [ ] Images with alt text (target keywords)
- [ ] Internal links (3-5 per article)
- [ ] Meta description (160 chars) with target keyword
- [ ] URL slug with keyword
- [ ] 1,200+ words (1,500+ for high-priority)
- [ ] Mobile-friendly formatting
- [ ] Call-to-action at end

**Day 1 - Publish:**

## Local SEO (Multi-City)

For each of 43 cities:
1. Create Google My Business listing
2. Build city-specific landing page
3. Get local directory listings (Yelp, Apple Maps)
4. Reach out to local bloggers
5. Partner with local businesses
6. Create city-specific blog posts

Example URL structure:
- /cities/new-york
- /cities/los-angeles
- /cities/london
- /cities/paris

Each city page:
- Services available
- Popular bookings
- Local providers
- Customer testimonials
- City guide blog post
